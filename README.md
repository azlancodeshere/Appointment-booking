# Syncora - Appointment Booking System

Syncora is a full-stack appointment booking platform where clients can discover professionals and book appointments based on their available time slots.

## Features

- User Registration & Login
- JWT Authentication
- Client and Professional roles
- Doctor appointment booking
- Lawyer appointment booking
- Barber appointment booking
- Trainer appointment booking
- Professional availability management
- Appointment requests
- Confirm / Cancel appointments
- Client appointment dashboard

## Tech Stack

### Frontend
- React.js
- React Router
- Tailwind CSS
- Axios
- React Icons
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Cookie Parser
- CORS
